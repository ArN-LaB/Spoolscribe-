**Portable preferences, recoverable backups and notarised macOS.** This release brings six-tab settings, portable preference previews, local ZIP backups, restoration and explicit undo into the Desktop workflow. Persistent recovery conflicts retain third-party or ambiguous files until resolved instead of claiming a complete restore.

## What changes for you

Value provenance, About information, opt-in diagnostics and shared printer setups are aligned. Windows temporary-file handling is corrected without dropping ownership checks. The new arm64 macOS build is Developer ID signed and newly notarised by Apple. Preference JSON and backup ZIP files are not encrypted; AES-256-GCM remains future work.

Windows/Linux archives are x86_64. macOS is **Apple Silicon arm64 only**: the
new application has a Developer ID Application signature and Hardened Runtime,
Apple **Accepted** with a reviewed log (0 issues, 67 ticket entries), and a stapled
ticket. Signature/ticket survived packaging and fresh extraction; Gatekeeper
returned **Notarized Developer ID — PASS**. Keep Gatekeeper enabled and open
the extracted app normally. The highest component-declared minimum is
**macOS 15.0**; the bounded native walkthrough ran on macOS 27.2. Intel/universal2
and older Windows/Linux versions are not qualified by this release.
