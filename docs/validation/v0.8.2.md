## Sources and software gates

This release integrates the B14 workspace refinements: immediate hardware/tag state, a single navigation menu, catalogue progress beside the catalogue, visible unencrypted-export notices, responsive About and narrow-window layouts, idle layout fitting, readable confirmations and an inset status line. The final refresh-exit message correctly states that completed steps may have changed local data; it does not promise a global rollback.

The final source tree is tested in the existing CI matrix: Ubuntu Python 3.10 and 3.12, Windows Python 3.12 and macOS Python 3.12. The linked release records the exact source SHA, CI run, discovered tests, actual skips and runner versions. Earlier 852-test and focused QA results belong to their historical source states; they are not substituted for the final-source CI run.

Three new native builds exercise the offline frozen TLS, catalogue/NFC, colour and digitally decoded SSQR1 probes. Windows and Linux archives come from CI. The published macOS arm64 archive is a separate fresh build of the same source, Developer ID signed with Hardened Runtime, Apple Accepted, stapled and Gatekeeper-assessed after fresh extraction. The CI ad hoc macOS intermediate is not published.

## Bounded fixes and retained limits

The Settings/preference-export lifecycle crash was reproduced before its fix and the corrected path passed bounded checks. This is distinct from the older, unexplained macOS SIGSEGV: no global crash-free guarantee is made. Dialog and geometry checks cover the measured Cocoa scenarios, not every screen, font or operating-system release.

Preference JSON and backup ZIP files are not encrypted. AES-256-GCM and mobile Companion distribution are not delivered. Physical printer/reader use, NFC writing/read-back, paper printing and a standard-account first launch with effective browser quarantine remain unmeasured unless separately documented. Keep Gatekeeper enabled; no quarantine bypass is required by the installation instructions.
