## Failures and corrections retained

The [first push](https://github.com/ArN-LaB/Spoolscribe-/actions/runs/41293604627)
failed on Windows because a translation test read UTF-8 source as cp1252,
raising `UnicodeDecodeError` on `0x90`. New test reads/writes became explicitly
UTF-8; application logic did not change.

The [first green full matrix](https://github.com/ArN-LaB/Spoolscribe-/actions/runs/41294045043)
passed 267 tests/configuration and three builds on `22ddaf1`. Download checks
then found CRLF translation JSON on Windows: equivalent JSON, different bytes.
`.gitattributes` now covered `translations/** -text`, and workflow comparison
included that directory: 194 resources instead of 193.

Push runs superseded by manual validation were cancelled by concurrency rules.
A rerun of the old SHA was cancelled after SSH refused the following push.
Cancelled runs are not successful results; the authoritative candidate is the
final SHA/workflow above. Branch runs intentionally skipped tag matching and
publication; those were not claimed tested, and preparation had not yet created
`v0.3.5`. Main's required checks remained enabled without force-push/admin bypass.

## Infrastructure notices and remaining limits

GitHub announced the `ubuntu-latest` transition to Ubuntu 26 and possible macOS
arm64 queues. Those notices were not project failures. Linux required a recent
system with the README's Qt libraries; not every distribution/version was tested.
Tracked catalogue, 48 Orca profiles, Spoolman, RFID associations, firmware and
personal services were unchanged. Physical NFC writing/read-back and exhaustive
human acceptance across all three desktops were not performed. Native-speaker
translation review remained desirable; external diagnostics were not translated.

At candidate completion, integration/publication required a separate decision
and verification of public main/tag/assets. The candidate report itself did not
create a release.
