## Diagnostic et corrections

1. [Premier push échoué](https://github.com/ArN-LaB/Spoolscribe-/actions/runs/41293604627) :
   Windows lisait une source UTF-8 en cp1252 dans le test de traductions ;
   `UnicodeDecodeError` sur l’octet `0x90`. Lectures/écritures des nouveaux tests
   désormais explicitement UTF-8. Aucun changement de logique applicative.
2. [Première matrice complète verte](https://github.com/ArN-LaB/Spoolscribe-/actions/runs/41294045043) :
   267 tests par configuration et trois builds réussis sur `22ddaf1`.
   Le contrôle supplémentaire des téléchargements a identifié des fins de ligne
   CRLF dans le JSON de traductions Windows : contenu JSON équivalent, octets
   différents. `.gitattributes` couvre maintenant `translations/** -text` et le
   workflow compare ce dossier à Git : 194 ressources au lieu de 193.
3. Les runs de push remplacés par un lancement manuel ont été annulés par la
   règle de concurrence. Une relance sur l’ancien SHA a été annulée après un
   refus SSH du push suivant. Ces runs annulés ne comptent pas comme réussites.
   Les résultats retenus sont ceux du SHA et de l’exécution finale indiqués en tête.

Sur une branche, le contrôle de correspondance du tag et le job de publication
sont ignorés par conception. Ils ne sont pas présentés comme validés : un tag
`v0.3.5` n’a pas encore été créé par cette préparation. Les contrôles obligatoires
de `main` restent en place, sans force-push ni contournement administrateur.

## Avertissements d’infrastructure

GitHub signale la migration de `ubuntu-latest` vers Ubuntu 26 et des files d’attente
possibles sur macOS arm64. Ces notices ne sont pas des erreurs du projet. Le ZIP
Linux reste destiné à un système récent avec les bibliothèques Qt indiquées dans
le README ; toutes les distributions et versions de Linux ne sont pas testées.

## État et limites

Le catalogue suivi, les 48 profils Orca, Spoolman, les associations RFID,
le firmware et les services personnels ne sont pas modifiés. Les tests
physiques d’écriture/lecture NFC et la recette humaine exhaustive des trois
interfaces restent non exécutés. La relecture des traductions par des locuteurs
natifs reste souhaitable ; les diagnostics techniques externes ne sont pas traduits.

La candidate est prête pour la décision d’intégration et de publication.
Ce rapport ne vaut pas création de release : la version publique, `main`, le tag
et les assets doivent être vérifiés séparément lors de cette opération.
