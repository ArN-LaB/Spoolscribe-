# Validation — SpoolScribe v0.8.0 Pre-release

[Previous validation](v0.7.0.md) · [Stable v0.3.5](v0.3.5.md)

Guided colour entry, user-declared device presets, contextual list ΔE, content-sized
dialogs, reviewed OpenTag3D temperature proposals and a digital-first QR workflow.
The source encoders and SSQR1 contract remain unchanged. Presets never imply an
instrument calibration, measured catalogue or undocumented comparison conditions.

Publication requires four complete test jobs (Linux Python 3.10/3.12, Windows and
macOS Python 3.12), three native builds with frozen probes, three ZIP archives and
three matching SHA-256 files. The workflow checks uploaded bytes before publishing
with `prerelease=true`, `draft=false`, `latest=false`. v0.3.5 remains the latest stable.

Final executed results, PR/commit links and public download hashes are recorded
below after the release run. No phone, physical print, instrument, tag write/read-back
or exhaustive printer/reader configuration acceptance is claimed. Companion store
links are not yet available; [one common information page](../COMPANION.md) is provided.
