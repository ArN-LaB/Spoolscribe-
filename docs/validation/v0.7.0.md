# Validation — SpoolScribe v0.7.0 Pre-release

[Download v0.7.0](https://github.com/ArN-LaB/Spoolscribe-/releases/tag/v0.7.0) ·
[Colour measurements](../COLOUR_MEASUREMENTS.md) · [Previous validation](v0.6.0.md).
**v0.3.5 remains the latest stable release.** Previous tags and binaries are retained.

## Scope and measured baseline

Desktop P1 adds HEX/RGB/CIELAB entry, labelled paste, explicit CSV/TSV mapping and
a separate local measurement registry. Against declared catalogue HEX, results
remain indicative. Lab ranking requires documented D65/2° conditions; other
conditions are preserved without ranking. No instrument, SDK, driver, new NFC
protocol or Companion feature is introduced.

The [validated P1 baseline](https://github.com/ArN-LaB/Spoolscribe-/actions/runs/41830176597)
at `e1902983f3abf165667201b71653289813d68837` executed 589 tests on each of Linux
3.10/3.12, Windows 3.12 and macOS 3.12, then three real builds. Six HEX goldens,
34 Sharma vectors and 12 OpenSpool/OpenTag3D/NDEF/SSQR1 digests remained unchanged.
Each binary passed measurement/TLS/catalogue/resource probes and 24 SSQR1 cases
with 30 independent digital scans. No physical acceptance is inferred.

## Release gate for v0.7.0

Version preparation adds a test evaluating the actual workflow condition for
v0.7.0 and v0.3.5, then exercising the publication step offline. It requires
`prerelease=true`, `draft=false`, `latest=false` for v0.7.0 and preserves the
stable-channel behavior. The full suite contains **590 tests**.

The tag workflow must pass all four test configurations, then all three native
builds and their frozen probes. All three ZIPs and SHA-256 files are checked
before upload; uploaded bytes are downloaded and checked before the draft is
published. A skipped job does not count as an executed test.

The [release page](https://github.com/ArN-LaB/Spoolscribe-/releases/tag/v0.7.0)
contains the exact workflow link for its binaries. This page records the tested
P1 baseline and publication gates; the final agent report
`18-CODEX-INTEGRATION-RELEASE-COLOR-P1.md` records actual release execution,
commits, download hashes and remaining limits in the local working dossier.

## Remaining limits

- No physical colour instrument, authentic manufacturer export, RFID writing or printer read-back acceptance.
- No exhaustive human desktop or native-speaker validation. CI uses native executables with Qt offscreen.
- macOS: Apple Silicon, ad hoc signature, no Apple notarisation. Windows: no commercial signing certificate.
- Linux: recent glibc and documented external Qt/XCB/XKB libraries; an offscreen probe does not certify X11/Wayland.
- An editor ignoring storage locks can still race between the final revision check and replacement.
