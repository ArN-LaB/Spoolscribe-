# SpoolScribe v0.8.1 — software release validation

[Release, platform archives and SHA-256](https://github.com/ArN-LaB/Spoolscribe-/releases/tag/v0.8.1) · [Release policy](../RELEASE_POLICY.md) · [Help](../wiki/Home.md)

## Final local sources

The 0.8.1 version bump preserves the validated Desktop 002 business sources and
F1 recovery fixes. One full offline suite on macOS arm64 / Python 3.12.13 / Qt
6.11.3 completed with **822 tests, OK, no skips**, on 8 November 2026 (Shanghai),
156.320 seconds of unittest runtime. Source/test SHA-256 snapshots taken before
and after are identical. This is software evidence, not physical NFC/printing
certification. Recovery ownership and residue scenarios remain covered; a
pathname check followed by a file operation is not claimed atomic.

The first CI run exposed seven Python 3.10 test-setup errors: `enterContext`
is unavailable in that interpreter. The fixture now uses `patch.start()` and
`addCleanup(patch.stop)`, preserving the same assertions and restoration.
The seven affected tests passed locally after this test-only correction;
the final CI must validate the corrected commit on all four configurations.
No application source changed for this correction.

**31 current UI captures** were regenerated from public fixtures, offline, with
no personal catalogue. [Hashes and provenance](../images/README.md).

## Release gates and provenance

The release is gated by the existing four CI test configurations (Ubuntu Python
3.10/3.12, Windows 3.12 and macOS 3.12), fresh Windows/Linux packaging and frozen
TLS, catalogue/NFC, colour and independently decoded digital SSQR1 probes. The
successful workflow and exact source commit are linked in the release notes.
The tag does not trigger a second automatic ad hoc macOS publication.

The published macOS arm64 archive must come from a fresh local export of that
source commit, Developer ID signed with Hardened Runtime, Apple Accepted with
its log checked, stapled, packaged after stapling and assessed on a fresh
extraction. The exact measured minimum OS, notarisation result and all archive
SHA-256 values are reported with the release. Intel/universal2 is not supplied.
The old v0.8.0 tag and six assets are preserved unchanged.

## Delivered behavior and limits

- Six settings tabs, explicit refresh cadence, portable preference JSON preview.
- Local ZIP backups, restoration preview/undo and persistent recovery conflicts.
- Effective-value origin/reliability, translated About and optional diagnostics.
- Shared printer configuration, explicit confirmation and blocked uncertain NFC exports.
- Preference JSON and backup ZIP files are **not encrypted**; AES-256-GCM is future work.

The historical macOS SIGSEGV was not reproduced by the bounded diagnostic. Its
cause is not established and no crash fix is claimed. The owner authorised this
release and investigation only on a new incident. No hardware printer/reader,
physical tag writing/read-back, paper print or mobile distribution is certified
by these software checks.
