# SpoolScribe Companion

[SpoolScribe Desktop](../README.md) · [Digital QR transfer](QR_FORMAT.md)

**Mobile NFC writing — coming soon.** This is the shared availability page for
iOS and Android. Desktop links here rather than guessing your phone from your
computer’s operating system.

| Platform | Availability |
| --- | --- |
| iOS | Development/testing in progress. An official App Store link will be added when published. |
| Android | No official public download link available. |

The desktop application can already display and save a **SSQR1 QR containing the
complete NFC message**, without a server. An ordinary QR scanner shows transfer
text; writing the NFC tag requires a compatible Companion implementation and phone.
This page does not announce a released mobile application or hardware certification.

Only verified official download links will be listed here. Desktop v0.8.0 remains
a [Pre-release](https://github.com/ArN-LaB/Spoolscribe-/releases/tag/v0.8.0);
[v0.3.5](https://github.com/ArN-LaB/Spoolscribe-/releases/tag/v0.3.5) remains stable.
